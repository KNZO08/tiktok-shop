    Télécharger

    Poster sur TikTok

    1. Scanne le QR code avec l'appareil photo de ton téléphone.
    2. Appuie sur « Ouvrir dans TikTok » et choisis TikTok : la vidéo s'ouvre, la légende est déjà copiée.
    3. Dans la description, appui long → Coller. Ajoute le panier orange et publie.

    Le téléphone doit être sur le même Wi-Fi que l'ordinateur. Si macOS demande d'autoriser les connexions entrantes pour « Python », choisis Autoriser. Le lien expire au bout de 3 heures.

    Réglages

    Clé API Anthropic facultatif

    Sans clé, c'est Claude (dans la conversation) qui regarde les captures et écrit chaque script. Avec une clé (console.anthropic.com → « API keys »), tout devient automatique, même quand la conversation est fermée. Elle reste sur ton ordinateur.

    Voix off (toujours la même)
    Mes comptes TikTok gratuit

    Le bouton « Publier sur TikTok » ouvre TikTok Studio dans le profil Chrome de ton compte, copie la légende et montre la vidéo : tu n'as plus qu'à la glisser, ajouter le panier orange et publier. Un profil Chrome par compte TikTok (connecte-toi une fois dans chacun).

    Envoi automatique en brouillon option payante

    Pour envoyer une vidéo dans tes brouillons TikTok en un clic : crée un compte sur upload-post.com (TikTok demande une offre payante), connecte ton TikTok, puis copie ici ta clé API et le nom de ton profil. Ensuite, dans l'appli TikTok, tu ajoutes le panier orange et tu publies.
